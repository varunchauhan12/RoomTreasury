# RoomTreasury UI references

Fastify serves the existing native frontend and a local React component bundle. Published components live in `frontend/ui` with their original headers. The bundle uses shadcn/ui Card and Tabs, and Magic UI BlurFade for receipt details when motion is enabled.

| Reference | Planned use |
| --- | --- |
| [Halftone Background](https://kokonutui.com/docs/backgrounds/halftone-background) | Published component in the Overview header |
| [Metric Card](https://kokonutui.com/docs/cards/metric-card) | Published component with a Finance snapshot mode |
| [Widget Grid](https://kokonutui.com/docs/cards/bento-grid) | Overview layout and future dashboard widgets |
| [Currency Transfer](https://kokonutui.com/docs/cards/currency-transfer) | Published component in Finance receipt details, with simulation-specific copy |
| [Flick Card](https://kokonutui.com/docs/cards/card-flip) | Optional proposal summary and detail |
| [Spending Ring](https://kokonutui.com/docs/cards/spending-ring) | Published component for approved delivery budget breakdown |
| [Lightbox Grid](https://kokonutui.com/docs/cards/lightbox-grid) | Proposal artifact gallery |
| [File Upload](https://kokonutui.com/docs/inputs/file-upload) | Existing owner artifact upload flow |
| [Stay Picker](https://kokonutui.com/docs/inputs/stay-picker) | Project date ranges when a schedule is defined |
| [AI Input Selector](https://kokonutui.com/docs/ai/ai-prompt) | Project brief intake |
| [AI State Loading](https://kokonutui.com/docs/ai/ai-loading) | Persisted agent processing states |
| [AI Text Loading](https://kokonutui.com/docs/ai/ai-text-loading) | Brief loading feedback in the agent workspace |
